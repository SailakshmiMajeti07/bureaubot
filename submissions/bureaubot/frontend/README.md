# BureauBot frontend

A responsive React, Vite, and Tailwind CSS application for BureauBot's India government-service guidance.

## Pages

- Home
- Chat Assistant
- Eligibility Checker
- Document Checklist
- Government Services
- Application Tracker

Set `VITE_API_URL` to the FastAPI backend URL if it is not running at `http://127.0.0.1:8000`.

```bash
npm install
npm run dev
```

Run `npm run build` before deployment.
